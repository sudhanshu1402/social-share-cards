How to export these as PNGs (GitHub social preview = 1280×640)

Each card below is exactly 1280×640. To upload one: repo → Settings → Social preview → Edit → Upload an image (profile card goes on the sudhanshu1402/sudhanshu1402 repo).
  1. Easiest: open this file in Chrome, right-click a card → "Capture node screenshot" (DevTools → Elements → pick the .card → ⋮ → Capture node screenshot). Exports the exact 1280×640 PNG.
  2. Or macOS ⌘⇧4, drag the card bounds (the bordered box).
  3. Or ask me to render all 7 to PNG via the browser tool.
